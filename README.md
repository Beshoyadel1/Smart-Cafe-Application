# Smart Cafe Application

A Flutter cafe ordering app with a customer-facing menu and checkout flow, plus a separate admin/employee panel for managing items and incoming orders.

## Features

- Browse the menu with categories and item details
- Cart with quantity editing and card checkout
- Order placement and order tracking
- Admin panel: manage menu items, view and handle orders
- Employee view for day-to-day operations
- Customer feedback screen

## Tech Stack

- Flutter & Dart
- Firebase: Authentication, Cloud Firestore, Storage
- State management: provider
- Card payments UI in the checkout flow
